기본 승리 조건

더 높은 점수를 가진 플레이어가 승리한다.

점수 획득 방법

• 1~100 중 숫자를 랜덤으로 뽑는다.

• 애드(Add): 본인 점수에 추가. 경기 중 12회 사용 가능.

• 스로우(Throw): 상대 점수 감점. 경기 중 3회 사용 가능.

• 총 15회(애드 12 + 스로우 3) 종료 후 점수 비교.

동점 처리

① 스로우 제외 점수가 높은 플레이어 승리.

② 그래도 동점이면 타이브레이커 (1~100 뽑기, 높은 수가 승리, 반복).

라운드 진행 방식

• 예선전 / 16강전 / 8강전: 단판전

• 준결승: 3판 2선승제

• 결승: 5판 3선승제

엘리미네이션 특별 룰 (16강~결승)

• 대진 내 이전 라운드 점수가 높은 선수 = 상위 시드.

• 상위 시드 패배 위기 시: +50점 추가.

• 상위 시드 승리 시: +100점 추가.

• 추가점에도 하위 시드가 앞설 경우 → 업셋(Upset).

승점 체계

• 경기 승리당 +0.5pt 즉시 지급.

• 라운드 시즌 포인트는 경기 결승 종료 후 순위 기준 일괄 지급.

▸ 세트 구성 & 세트 승리 조건

각 세트 = 3경기 (경기1 → 경기2 → 경기3 순서로 진행, 이전 경기 완료 후 다음 활성화)
① 세트 총점 차 ≤ 200점

② 세트 총점 차 ≥ 201점
세트 내 경기 승리 수와 무관하게 총점이 더 높은 팀이 세트 승리
ex) 세트 내 경기 2:1로 앞서더라도, 총점 201점 이상 뒤지면 세트 패배

가치 평점

선수의 종합 경쟁력 지표로, 아래 공식으로 계산됩니다.

가치 평점 = log(승점) + 내 평균점수 ÷ 전체평균점수의평균
· 전체평균점수의평균 = 전체 선수 평균점수의 합 ÷ 전체 선수 수
· 소수점 넷째 자리까지 표기

팀 가치 평점 = 팀 소속 전체 선수의 가치 평점 합산

점수 가치도 (2028시즌~)

• 2028시즌부터 도입. 경기 중 애드(Add) 액션마다 실시간 평가 (경기당 최대 15회/선수).

• a = 상대 현재 점수, b = 내 현재 점수, x = 이번 뽑은 점수

① 지고 있음 (a − b > 0):
가치도 = 10x / (a−b), 범위 [1, 10]
단, x ≥ (a−b) 이면 역전 → 무조건 10점
ex) 79점 뒤지는 상황에서 80점 → 10점 / 80점 뒤지는 상황에서 70점 → 8.75점
② 이기거나 차이 ≤ 100점 (b − a ≤ 100):
가치도 = x / 10, 범위 [1, 10]
③ 100점 초과 리드 (b − a > 100):
가치도 = x / 10, 범위 [2, 8]

* 세부기록 탭 '점수 가치도'는 경기별 평균 가치도를 선수별로 집계.
